# Candidate Messages — US12

Hiring Manager page with fictional submissions for the saved Job Posting and sample Training Coordinator job. Select an individual, an arbitrary set of candidates, or filter by stage and select all shown. Compose one message, send it, and see confirmation and browser-local history with recipient names, stage snapshots, time, and message text.

Stage options are Submitted, In review, Interview, and Not moving forward. Stage changes save immediately and update filter counts and membership. Switching filters or jobs clears recipient selection to avoid hidden recipients. Changing jobs also clears unsent text. Sending validates at least one recipient and nonblank text. Failed local storage writes do not record success.

This is a 2-point prototype. Sending is simulated; no emails, texts, or external messages are delivered. Stage changes and history exist only in this browser. It is a separate sample submissions dataset, not a live connection to Candidate Matches, My Applications, or external employer systems. No automatic rejection-only campaign or scheduling workflow is included.

## Acceptance checks

1. Select one candidate and send a message: confirmation says one recipient; history lists that person only.
2. Select multiple candidates from different stages and send: history lists the exact selected recipients.
3. Filter Interview and select all shown: only that stage's candidates are selected. Changing filters clears selection.
4. Change a candidate stage: counts and group membership update immediately, and the stage survives refresh.
5. Send to Not moving forward using the same group selection workflow.
6. Sending with no recipients or a blank message shows a clear validation message.
7. Refresh: per-job history and stage changes remain. Switching jobs shows independent stages and history.
8. Candidate Messages is registered in the Hiring Manager page selector on all eight pages; desktop and mobile remain usable.
